# 周一见 · 课题组组会排班

一个无需后端、无需构建的静态组会排班页面。支持 GitHub Pages，也可直接打开根目录中的 `index.html` 使用。

## 排班与名单

- 每周一安排一位在校同学，按名单顺序循环轮值。
- 支持添加、改名、删除同学，以及调整轮值顺序。
- 提供“在校”“实习”“暂停”三种状态。实习或暂停期间不参与未来排期，恢复在校后重新参与。
- 过去日期的排期会保留当时的主讲姓名；今天及之后的安排可随名单变化自动更新。
- 支持按月份查看、CSV 导出、打印或保存 PDF，以及 JSON 备份和恢复。
- 支持手机布局、浅色与深色外观。

初始名单从 **2026 年 10 月 19 日**开始排期，共 15 周，至 **2027 年 1 月 25 日**。参考图片未标注年份，因此默认采用 2026 年；日期、周数和姓名均可在页面中修改。

每周一均排会，不会自动跳过节假日。初次打开时，已过去日期的排期按默认名单生成，并不代表真实出席记录。更改首场日期会重新生成整份排期并清除原有历史记录，建议先备份。

## 数据保存

名单、排期设置和历史记录仅保存在**当前浏览器的本地存储**中。页面没有后端，不会自动同步到其他电脑、手机或浏览器，也不会将名单修改提交到 GitHub。

同一浏览器、同一网址下的标签页会接收彼此保存的修改。更换设备、浏览器或访问网址前，请先导出 JSON 备份，再到新环境导入。本地文件、localhost 预览和 GitHub Pages 是不同的存储环境，各自保存数据。

## GitHub Pages 部署

将本目录的文件放在仓库根目录。在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**，选择存放这些文件的分支，并将目录设为 **/ (root)** 后保存。

本项目使用相对资源路径，可以部署在 GitHub Pages 的项目子路径下。`.nojekyll` 用于直接发布静态文件，无需 Jekyll 或其他构建步骤。

## 本地预览

在仓库根目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

访问 [本地预览](http://127.0.0.1:4173)。也可以直接打开 `index.html`；使用服务器预览时，请留意上述存储环境差异。

## 验证

需要已安装 Node.js：

```sh
node --test scheduler.test.cjs
node --check app.js
node --check scheduler.js
```

测试覆盖跨年周一日期、循环轮值、实习与暂停、全员不参与、历史记录保留、删除主讲人后的续排，以及导入数据校验。

## 文件

- `index.html`：页面结构与入口。
- `styles.css`：响应式样式及主题。
- `app.js`：名单管理、交互、本地保存与导入导出。
- `scheduler.js`：排期计算及数据校验。
- `scheduler.test.cjs`：排期引擎测试。
- `.nojekyll`：GitHub Pages 静态发布标记。

本项目采用原生 HTML、CSS 和 JavaScript，无第三方前端依赖。
