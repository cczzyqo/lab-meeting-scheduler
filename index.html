将本机草稿发布为课题组共享排期。

普通访客可以在本机起草。只有拥有仓库写入权限的成员，才能完成上传并发布共享排期。

  1. 下载排期文件

    下载当前草稿，文件名必须是 schedule.json。

  2. 上传到 GitHub 仓库

    上传文件，覆盖仓库根目录的同名文件 schedule.json，然后选择 Commit changes，提交到 main 分支。

    打开 GitHub 上传页 ↗

  3. 确认共享排期已更新

    等待 GitHub Pages 更新后，回到本页面点击“检查发布结果”。确认发布成功后，其他同学就能看到新排期。
